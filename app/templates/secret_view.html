Access

Who can see this secret is decided by its access mode and the role bindings below. Project admins always have full access.

  • Inherit - team and project role bindings apply, plus any secret-level bindings listed below.
  • Restricted - only the subjects bound below (plus project admins) can access this secret; team and project roles do not apply.

Warning: switching to Restricted immediately cuts off team and project access for everyone not bound below (project admins are unaffected).

Machine accounts use project tokens (separate from this list). Reveal approval is an additional layer on top of the reveal permission.

Bind a user, group, or machine account to a secret role. Use Restricted mode (above) so only these bindings apply. Users outside the team see the secret under Workspace → Shared secrets (not allowed if reveal approval is required).
